🍊 Foodly

A modern food discovery experience combining editorial-style design, interactive 3D visuals, and a smooth browsing experience.

Foodly is a modern food-focused web application built with React.
The project combines a magazine-inspired interface with interactive animations and a custom 3D hero section to create a more engaging way to explore food content.

🎨 Design

Foodly was designed around the idea of turning a food website into a more visual and editorial experience.

The interface focuses on:

* Strong typography
* Food imagery
* Spacious layouts
* Smooth animations
* Interactive elements
* A custom 3D visual experience

The goal was to move away from a standard food-listing layout and create something that feels closer to a modern digital food magazine.

🚀 Getting Started

Prerequisites

Make sure you have:

* Node.js installed
* npm installed
* Git installed

Installation

Clone the repository:

git clone https://github.com/israoun11/Foodly.git

Navigate to the project:

cd Foodly

Install dependencies:

npm install

Start the development server:

npm run dev

The application will be available locally through the Vite development server.
